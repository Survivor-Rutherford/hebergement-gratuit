# Nuvora

Landing page statique et responsive pour une offre fictive d’hébergement web gratuit.

## Aperçu local

Ouvrez `index.html` dans un navigateur ou lancez un serveur statique :

```powershell
python -m http.server 8080
```

Puis visitez <http://localhost:8080>.

## Déploiement

Le site est compatible avec GitHub Pages et ne nécessite aucune compilation.
